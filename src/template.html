01 Featured case study

Commodity Forecasting Research Lab

Weekly forecasts for energy, metals and agricultural futures, built to answer a harder question than “what will the price be?”: does a sophisticated model actually beat a naïve baseline, and how uncertain is it?

{{GH}} View code
Pythonstatsmodels / pmdarimaProphetStreamlitpytestCI · Py 3.10 & 3.12
01

Problem

Commodity forecasts are easy to make look convincing. The question is whether a model beats transparent benchmarks out-of-sample, and how to present uncertainty and weather or supply/demand assumptions without implying causality.

02

Approach

Real futures histories from Yahoo Finance (WTI, Brent, natural gas, gold, silver, copper, corn, wheat, soybeans) resampled weekly, then modeled with Auto-ARIMA / SARIMAX and Prophet. Open-Meteo weather for producing regions and STL decomposition add context.

03

Validation

Rolling-origin, one-step evaluation using only data before each forecast date. Last-value, drift and 52-week seasonal-naïve baselines, scored on MAE, RMSE, MAPE, sMAPE, MASE and directional accuracy.

MASE < 1 → better than the naïve error scale
MASE > 1 → worse than the naïve error scale
04

Result

A Streamlit research dashboard with six workbenches: market overview, forecast with intervals, a baseline validation leaderboard, weather context, decomposition, and producer-risk views with explicit supply, demand and weather scenario controls. Tests and CI run on Python 3.10 and 3.12.

Stated limitations: contract-roll effects, regime change, correlation ≠ causation. Educational, not trading advice.
